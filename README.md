# Website Structure

## Header

Contains 1 `<nav>` as a child.
`<nav>` contains 1 `<ul>` as a child.
`<ul>` contains `<li>` elements as many as you want.
Each `<li>` element contains `<a class="menu-link">` elements.

## Introduction

Introduction section is a grid consists of 3 parts. 1fr 8fr 1fr.
The most left and the most right parts are empty.
Content lies in 8fr part.

## main-contanier

main-container is a grid consists of 3 parts. 1fr 8fr 1fr.
The most left and the most right parts are empty.
main content lies in 8fr part.
